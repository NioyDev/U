OFERTA ACADÉMICA - SOFTWARE

Bachillerato Técnico Vocacional en Desarrollo de Software

Duración de 3 años. Al graduarte podrás insertarte en el ámbito laboral en las áreas afines a esta especialidad.

En este bachillerato recibirás formación técnica necesaria para desarrollar aplicaciones de escritorio, intranet, web y dispositivos móviles. También obtendrás los conocimientos necesarios para la Administración de Bases de Datos relacionales.

De igual manera, adquirirás competencias básicas en el área de redes, ya que aprenderás a crear, administrar y configurar redes de área local, configurar dispositivos de red, y configurar servicios básicos en máquinas virtuales. Además, obtendrás habilidades en el mantenimiento preventivo y correctivo de computadoras, que te permitirán ensamblar y/o sustituir partes de computadoras.

Competencias Técnicas

  • Analizar los requerimientos de clientes para desarrollar sistemas
  • Desarrollo de Lógica de programación
  • Diseñar soluciones informáticas y sus componentes utilizando lenguaje Unificado de Modelado (UML)
  • Administración de bases de datos relacionales utilizando SGBD como Workbench, phpMyAdmin, Postgresql, HeidiSQL, SQL Server Express
  • Desarrollar aplicaciones web bajo arquitectura cliente-servidor utilizando lenguajes como Python, Java, C#, y frameworks como Angular, React por medio de JavaScript o TypeScript
  • Diseñar y configurar una red virtual y sus dispositivos utilizando packet tracer aplicando topologías de redes conocidas
  • Elaborar manuales de usuarios utilizando estándares de calidad apegados a las normas ISO e ITIL
  • Implementar buenas prácticas de desarrollo de Software
  • Competencias en tecnologías emergentes (Inteligencia Artificial, Diseño y manipulación de realidad virtual, impresión 3D, video mapping)

Campos de Trabajo

  • Soporte para el mantenimiento de aplicaciones
  • Capacitación para el desarrollo de Software
  • Pruebas y Control de calidad de sistemas
  • Cloud Computing (Desarrollo de Aplicaciones que se ejecutan desde la Web)
  • Desarrollo de Componentes web
  • Técnico de Aseguramiento de Calidad
  • Desarrollador de sitios y aplicaciones Web
  • Diseñador de Sistemas
  • Diseñador y Administrador de Base de datos
  • Instalador y configurador de Redes LAN
  • Operador de Sistemas Informáticos
  • Documentador de Sistemas
  • Ventas de soluciones de Software
